## 2. 付费版流程（自动隧道）

### 2.1 首次使用流程

```
┌─────────┐
│ 用户    │
└────┬────┘
     │
     │ 1. 下载 iOS App
     ▼
┌─────────────────┐
│ iOS App 启动    │
│ RevenueCat 初始化│
└────┬────────────┘
     │
     │ 2. 在本地电脑运行
     ▼
┌──────────────────────┐
│ $ msctl serve --relay│
└────┬─────────────────┘
     │
     │ 3. msctl 自动启动 cloudflared
     ▼
┌─────────────────────────────┐
│ cloudflared 建立隧道         │
│ 输出: https://xxx.try...com │
└────┬────────────────────────┘
     │
     │ 4. msctl 上报隧道地址
     ▼
┌──────────────────────────────┐
│ POST /tunnel                 │
│ {                            │
│   user_token: "abc123",      │
│   tunnel_url: "https://..."  │
│ }                            │
└────┬─────────────────────────┘
     │
     │ 5. 存储到 Workers KV
     ▼
┌──────────────────────────────┐
│ KV["tunnel:abc123"] = {      │
│   tunnel_url: "https://...", │
│   updated_at: "2026-05-28"   │
│ }                            │
└────┬─────────────────────────┘
     │
     │ 6. iOS App 轮询获取隧道地址
     ▼
┌──────────────────────────────┐
│ GET /tunnel/abc123           │
│ 每 10 秒查询一次，最多 5 分钟 │
└────┬─────────────────────────┘
     │
     │ 7. 获取到隧道地址
     ▼
┌──────────────────────────────┐
│ {                            │
│   tunnel_url: "https://...", │
│   status: "active"           │
│ }                            │
└────┬─────────────────────────┘
     │
     │ 8. iOS App 连接隧道
     ▼
┌──────────────────────────────┐
│ 连接成功！                    │
│ 记录 trial_start_time        │
│ 开始 14 天试用               │
└──────────────────────────────┘
```

## 5. msctl 心跳保活流程

```
┌──────────────────┐
│ msctl serve      │
│ --relay          │
└────┬─────────────┘
     │
     │ 启动时
     ▼
┌──────────────────────────────┐
│ 1. 启动 cloudflared          │
│ 2. 获取隧道 URL              │
│ 3. POST /tunnel (上报)       │
└────┬─────────────────────────┘
     │
     │ 每 5 分钟
     ▼
┌──────────────────────────────┐
│ 心跳任务                      │
│ POST /tunnel (更新 TTL)      │
└────┬─────────────────────────┘
     │
     │ Workers KV 自动续期
     ▼
┌──────────────────────────────┐
│ KV["tunnel:abc123"]          │
│ TTL 重置为 30 分钟            │
└────┬─────────────────────────┘
     │
     │ msctl 退出时
     ▼
┌──────────────────────────────┐
│ DELETE /tunnel/abc123        │
│ 清理状态                      │
└──────────────────────────────┘
```

## 6. 关键时间线对比

### 付费版（自动隧道）
```
Day 0    用户首次连接自动隧道，试用开始
Day 1-13 正常使用，设置页面显示 "Trial: X days remaining"
Day 14   试用到期，显示到期提示弹窗
         - 选项 1: 购买 → 继续使用自动隧道
         - 选项 2: 配置自定义服务器 → 免费版
```

### 免费版（自定义服务器）
```
Day 0    用户配置 Tailscale/ngrok
         连接自定义服务器
         无试用期限制，永久免费使用
```

## 7. 数据流向图

```
┌─────────────────────────────────────────────────────────────┐
│                        数据流向                              │
└─────────────────────────────────────────────────────────────┘

付费状态数据流:
iOS App → RevenueCat SDK → RevenueCat 服务器 → Apple 服务器
                ↓
         本地缓存 (SQLite)
         - is_paid
         - trial_start_time
         - last_checked_at

隧道地址数据流:
msctl → cloudflared → Cloudflare Tunnel → Cloudflare Workers KV
                                                ↓
                                          iOS App 轮询获取
                                                ↓
                                          连接到隧道 URL

用户请求数据流:
iOS App → Cloudflare Tunnel → msctl serve → Agent 处理
                                    ↓
                              WebSocket 流式响应
                                    ↓
iOS App ← Cloudflare Tunnel ← msctl serve
```
