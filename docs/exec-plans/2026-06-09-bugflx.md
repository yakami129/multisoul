# bugflx Implementation Plan

> **For agentic workers:** Use subagent-driven-development (recommended) or inline execution in the current session. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复移动端三处体验问题——快速工作流文案误导、Settings 端点在线状态不可信、Activity Done 子筛选间距过紧。

**Architecture:** 文案与布局为局部 i18n / StyleSheet 变更；端点在线链路接通既有 `pingAllEndpoints` + `updateLastSeen`，抽共享 `endpointLiveness` 模块供 Settings UI 与 API 拦截器复用；不引入定时轮询、不改 TargetPicker / Activity failedEndpoints 逻辑。

**Tech Stack:** React Native (Expo SDK 55), Zustand, expo-router, react-i18next, axios

**Spec:** [`docs/product-specs/2026-06-09-SPEC-bugflx.md`](../product-specs/2026-06-09-SPEC-bugflx.md)

- [ ] **Step 1: 创建 `endpointLiveness.ts`**

```ts
export const ENDPOINT_ONLINE_THRESHOLD_MS = 60_000;

export function normalizeEndpointBaseUrl(baseUrl: string): string { /* 从 endpointStore 迁入 */ }

export function endpointOnline(lastSeenAt: number | null, now = Date.now()): boolean {
  return lastSeenAt !== null && now - lastSeenAt < ENDPOINT_ONLINE_THRESHOLD_MS;
}

export function countOnlineEndpoints(
  endpoints: { last_seen_at: number | null }[],
  now = Date.now(),
): number {
  return endpoints.filter((ep) => endpointOnline(ep.last_seen_at, now)).length;
}
```

- [ ] **Step 1: `_layout.tsx` 启动 effect**


- [ ] **Step 3: `settings.tsx` focus ping**

```ts

useFocusEffect(
  useCallback(() => {
    void pingAllEndpoints();
  }, []),
);
```

- [ ] **Step 4: `endpointStore.addEndpoint` 写入后立即在线**

在 INSERT + set state 之后：

```ts
await updateLastSeen(id, Date.now());
```

注意：`addEndpoint` 仅在 `AddEndpointModal` healthz 成功后调用，符合 spec。

- [ ] **Step 5: `endpointClient.ts` 响应拦截器**

在 `axios.create` 后注册（仅新建 client 时一次）：

```ts
instance.interceptors.response.use((response) => {
  if (response.status >= 200 && response.status < 300) {
    const base = response.config.baseURL;
    if (base) {
      const normalized = normalizeEndpointBaseUrl(base);
      const { endpoints, updateLastSeen } = useEndpointStore.getState();
      const match = endpoints.find(
        (ep) => normalizeEndpointBaseUrl(ep.base_url) === normalized,
      );
      if (match) void updateLastSeen(match.id, Date.now());
    }
  }
  return response;
});
```

- 失败/非 2xx 不更新 `last_seen_at`
- 不实现 5s 去抖（spec 标注可选；重复写 DB 无害）

## 风险与注意事项

| 项 | 说明 |
|----|------|
| 多源 ping | 启动 + focus + foreground 可能连续触发；`Promise.allSettled` 静默，可接受 |
| `endpointClient` 缓存 | 拦截器仅在首次 `getEndpointClient` 创建时注册；已有实例在 `clearEndpointClients` 后重建 |
| Feature 边界 | `endpointClient`（`src/api/`）可 import `endpointLiveness` 与 `endpointStore`；不 deep-import settings components |
| 现有未提交 diff | 工作区含 workflow/specs i18n 等无关改动；实施时仅 stage bugflx 相关文件 |
| `EndpointList` 空状态 | 仍有硬编码英文（非本 spec 范围）；仅改 pill 与共享 liveness |
