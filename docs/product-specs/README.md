# `product-specs/` — 产品规格

回答 **"要做什么、为什么做"**。

## 内容范围

- 产品总规格（整个 MultiSoul 的目标、范围、模块划分）
- 单 feature 的产品规格（用户场景、验收标准、非目标）
- 不包含具体技术方案（那是 `../design-docs/` 的事）

## 命名约定

- 总规格：`SPEC.md`
- 单 feature：`SPEC-<kebab-case-feature>.md`，例如 `SPEC-list-refresh.md`

## 现有文档

| 文件 | 说明 |
|------|------|
