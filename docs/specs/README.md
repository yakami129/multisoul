# `docs/specs/` — 遗留路径（勿再作为权威落点）

本目录不是 MultiSoul 的正式规格树。**新的功能规格**请一律写入 [`../product-specs/`](../product-specs/)（例如 `SPEC-<kebab-case-feature>.md`）。

**实施计划**请写入 [`../exec-plans/`](../exec-plans/)（`YYYY-MM-DD-<feature>.md`）。

使用 **Superpowers**（如 `writing-plans`）产出规格时，**禁止**默认写入 `docs/specs/`；应写入 `docs/product-specs/`。详见 [`../superpowers/README.md`](../superpowers/README.md) 与根目录 [`AGENTS.md`](../../AGENTS.md)。
