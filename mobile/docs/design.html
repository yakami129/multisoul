Ink Console, Human Signal.

MultiSoul 的移动端应该像一块随身 Agent 控制台：黑色负责专注，cream 负责呼吸，cyan / coral / lime 只在系统真的发生变化时发光。

LogoSpace Grotesk 的硬朗字形承接 MultiSoul 字标。
Color七个品牌核心色被转译为状态语义。
Signal KitThink / Process / Decide / Done / Alert 成为 UI 状态语言。
01

Design Philosophy

这套移动端规范保留工具界面的效率，但把品牌手册里的友好机器人、纸感底色和信号色变成可执行的 UI 决策。

Ink Console

App 主体永远先是控制台。Ink Black 提供稳定背景，列表、工具调用、决策卡都在黑色系统里工作。

Cream as Breath

Cream 不是默认页面底色。它只出现在品牌、空状态、说明性容器和高价值确认里。

Signal, Not Decoration

Cyan、Coral、Lime 每次出现都表达 live、decide、done，不做随机点缀。

Friendly Machine

Mascot 可以柔软，控件必须稳定。结构优先可扫描、可触控、可重复操作。

04

Type + Layout

Space Grotesk 承接品牌 Display，Inter 保持 iOS 工具界面的清晰度。布局继续以 390×844 为基准。

Typography

  • 品牌标题：24-28px；工具页内品牌不超过 22px
  • 页面标题：22-24px Space Grotesk
  • 列表标题：13px Inter
  • 正文 / 问题：13-14px Inter
  • 摘要：12px；时间戳：10-11px
  • 标签 / chip：9-11px
  • 命令 / token / 日志：SF Mono
  • Agents header：18/22 + 22/26
  • 正文 lineHeight：1.35-1.45

Agents Type

  • Hero：title 18/22，body 12/17，chip 10/14
  • Stats：number 17/19，label 9/11
  • Search：Inter 14
  • Fleet：name 13/17，meta 11，path 10，status 10
  • Workflow：title 13/16，subtitle 11/14

Shape

  • Runtime avatar：30×30 tile，40×40 frame
  • 标准卡片：12px radius
  • Question card：16px radius
  • Tab Bar：50px rail + 28px safe padding / 30px radius

Motion

  • Think：轻微 pulse
  • Process：cyan ribbon
  • Decide：coral enter once
  • Done：lime check / fill

11

UI Checklist

任何 UI 变更提交前，用这份清单快速校准品牌、工程约束和移动端可用性。

  • 所有 hex 都在 Markdown §2 色板内，新增色已同步脚本。
  • Signal 色只表达状态，不做无语义装饰。
  • 字体只使用 Space Grotesk / Inter / SF Mono。
  • 页面仍是可扫描的工具界面，而不是营销页。
  • Tab Bar 为 50px rail + 28px safe padding、30px radius。
  • Agents 搜索框为 42-46px 高、21-23px radius。
  • Agent Fleet 行稳定在 62-70px，名称 13px，meta 11px，path/status 10px。
  • AskQuestion 明确突出用户决策。
  • Bottom Sheet 有 handle、scrim、顶部圆角和安全区处理。
  • 动效遵守 Reduce Motion。
  • Cream / mascot 用于品牌呼吸，不到处填充。
